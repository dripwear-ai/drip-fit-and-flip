# Drip Fit And Flip

Build an Tinder for fashion mobile app called Drip.
Basic idea is a smart fashion app with features such as: 
1. Virtual 3-D try-on with each cloth with putting your exact measurements and then it will create a exact digital print of that person which will show in 3-d exactly how that person will look.
2.  A smart AI-Powered wardrobe which will help them design outfits from the clothes image that user has uploaded and also suggest what can they buy what is not in their wardrobe.
The kind of UI for my app I want is a stylist UI with a the landing page want some style cards or images of person wearing the complete outfit. Then a fixed button at the screen bottom with two CTA discover and OOTD, at discover there will be a search bar with filters and then some swipe cards for shirts, jeans and all that apparel things which user can swipe right to open basically tinder type full screen swipe card , then once user opens the shirt section it will have similar tinder type full screen swipe cards with right swipe to save to Wishlist then left swipe and then swipe up to change the brand.
Then the other OOTD section we will include some complete outfits for user which they can buy in the similar full screen tinder type form and then two other features that we talked above which is ai smart wardrobe and virtual 3-d try on also in this section.

The above is the complete working plan of the app that i want.
Now want you to design a complete UI for this innovatively and accordingly to the above references and use some stylist color combos that resonates to this kind of app.
